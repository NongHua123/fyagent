## ハイライト

- **CC Switch v3.19.2 の統合:** annotated tag `v3.19.2` から完全な upstream
  ancestry を独立した二親 merge commit で統合しました。製品バージョンは FyAgent
  `0.3.0` のままで、upstream の番号には変更しません。
  [provenance ledger](../upstream/cc-switch-v3.19.2.md) を参照してください。
- **ネイティブビルド境界:** Linux/WSL から Windows/macOS を作るローカル cross-build
  を廃止しました。ローカルは現在のホストのみ、正式な Windows x64/ARM64、Linux
  x64/ARM64、macOS Universal は対応する GitHub native runner のみを使用し、QEMU
  fallback はありません。
- **mise + uv 開発環境:** canonical `mise run` task API、Node 24.19.0、pnpm
  10.12.3、Rust 1.97.1、Python 3.14.7 の正確な情報源、checksum で固定した uv、
  uv 専有の `.venv` と Python lock を導入しました。
- **自動 CI と Labeler:** PR/main の自動 CI、安定名 `CI / Required` の集約、PR
  コードを checkout・実行しない base-repository Labeler を復元しました。実際の
  remote trigger/run 証拠は公開ゲートのままです。
- **Native Fetch と DEP0040:** `cross-fetch` と
  `node-fetch@2 → whatwg-url@5 → tr46@0.0.3 → punycode` を削除しました。
  MSW/Tauri mock 経由で Node native Fetch の成功、text error、empty response、
  cross-realm を検証し、deprecation を失敗として扱います。
- **fail-closed 公開 transaction:** 手動 preflight は全 matrix を build/attest
  しますが公開しません。正式 `v0.3.0` は tag、製品版、source、trusted workflow、
  `origin/main` ancestry、same-SHA Required CI を結び付け、資産と証拠を厳密に検証した
  後だけ draft から stable Release へ移行します。

## ダウンロードと未署名インストール

### Windows

マシンのアーキテクチャに合う MSI を選んでください。アプリと MSI は意図的に未署名で、
SmartScreen が unknown publisher を警告する場合があります。続行前に正確なファイル名、
`download-manifest.json` の digest、build metadata、attestation 証拠を確認して
ください。SmartScreen や組織管理のセキュリティポリシーを無効化しないでください。

### macOS

DMG と ZIP は同じ Universal app を含みます。Developer ID 署名・公証がないため、
macOS が初回起動をブロックする場合があります。一度 FyAgent を開こうとした後、Apple
がサポートする **システム設定 → プライバシーとセキュリティ → このまま開く** を使用し
確認してください。Gatekeeper の無効化や quarantine 属性の削除は行わないでください。

### Linux

ホストに合う x86_64 または arm64 package を選んでください。AppImage、DEB、RPM は
すべて正式な必須形式です。Flatpak はローカル診断変換であり、正式な 10 installer に
含まれません。

## 正確な Release 添付契約

正式 Release は次の **10 installer assets** を正確に含む必要があります：

```text
FyAgent-0.3.0-macOS.dmg
FyAgent-0.3.0-macOS.zip
FyAgent-0.3.0-Windows.msi
FyAgent-0.3.0-Windows-arm64.msi
FyAgent-0.3.0-Linux-x86_64.AppImage
FyAgent-0.3.0-Linux-x86_64.deb
FyAgent-0.3.0-Linux-x86_64.rpm
FyAgent-0.3.0-Linux-arm64.AppImage
FyAgent-0.3.0-Linux-arm64.deb
FyAgent-0.3.0-Linux-arm64.rpm
```

さらに許可される evidence attachments は次の **3 files** だけです：

```text
download-manifest.json
build-metadata.json
artifact-attestation.sigstore.json
```

合計は **13** です。`download-manifest.json` は各 installer の SHA-256、size、
platform、architecture、format、source、tag、final URL を記録します。
`build-metadata.json` は 5 native target group を runner、toolchain、container、
workflow、source、Required CI に結び付けます。Sigstore bundle は 10 installer と
2 JSON evidence を対象にします。14 番目の standalone checksum file は公開しません。
欠落、重複、改名、空、余分な添付は公開を阻止します。

## 互換性

FyAgent v0.3.0 は runtime API、database、user-data migration を追加せず、次を維持します：

- database schema **16** と `~/.fyagent/fyagent.db`；
- `~/.fyagent` の settings、skills、自動 backup behavior；
- `fyagent://` deep link と bundle identifier `com.fyagent.desktop`；
- 既存 `FYAGENT_*` environment contract と Windows protected install boundary。

upgrade 前に重要な設定を backup してください。native build failure、attachment 不足、
identity/data-path drift、attestation 欠落はすべて NO-GO であり、縮小 matrix で代替
できません。

## Supply-chain model と受容したリスク

v0.3.0 には Windows/macOS signing credential、notarization、staple、signed mode、
protected Release environment、branch protection、branch/tag ruleset がありません。
least privilege と eligibility は workflow code が強制し、default `contents: read`、
限定 CI/Labeler/attestation/publish permission、full-SHA Actions、正確な repository /
workflow/source identity、attachment allowlist を使います。

これは administrator-enforced rule や environment approval より弱く、v0.3.0 で明示的に
受容する残存 supply-chain risk です。`main`、tag、Release が administrator-protected
だとは主張しません。署名や repository governance の強化は将来の別 decision です。

## 検証境界

local contract check が証明するのは source と workflow structure だけです。同一の正確な
`main` source SHA について、公開には次の実在証拠が必要です：

1. automatic `CI / Required` success；
2. Release を作らない 5-target unsigned preflight success；
3. exact `v0.3.0` tag-triggered formal workflow；
4. exactly 13 attachments の stable/non-prerelease public Release；
5. 再 download による name、count、version、architecture、size、SHA-256、Windows
   `NotSigned`、macOS unsigned/non-notarized、attestation bundle の独立検証。

1–4 は公開 gate、5 は公開後の独立 closeout 検証で、実施後にのみ記録します。
本文書を公開前に repository で読む場合でも、公開後に Release Notes として読む場合でも、
本文書自体は上記の項目を証明しません。インストール前に正確な 13 attachments とその
証拠を確認し、project が結果を記録するまで独立 closeout 検証の完了を推定しないで
ください。
