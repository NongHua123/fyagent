# 桌面验收自动化技术设计

使用有限 WDIO/Tauri 集成，但由测试构建注入 IPC fake 和固定窗口/配置数据。测试
夹具不含真实 Key、路径、PID 或用户信息；任何会触发系统进程、UAC 或外部网络的
接口必须在 fake 层失败关闭。几何 helper 记录关键元素边界，视觉比较只覆盖稳定
区域并在连续两次稳定采样后比对；全窗截图只作补充证据。

基线目录按平台、缩放、locale 隔离并由 `.gitattributes` 走 Git LFS。`update`
脚本显式生成/审查新基线，普通 test 命令只能比较。测试输出含脱敏日志、metrics
JSON、截图和 diff；报告将真实发布候选项保留为人工清单，不把模拟结果扩大成
运行时结论。

每个需求 ID 映射到单元、integration、desktop、visual 或人工项目；至少一个
可执行检查承担 P0 行为断言，视觉测试不可单独取代事务/安全单测。
